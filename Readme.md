## 🚀 Deployment

This site is deployed automatically via **GitHub Pages**.

| Setting | Value |
|---|---|
| Source | `main` branch, root `/` |
| Entry point | `index.html` |
| URL | `https://NinjaOfNeurons.github.io` |

No build step required — it's pure HTML/CSS/JS with zero dependencies.
